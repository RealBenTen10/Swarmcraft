## Required
- python 3.8 or newer (and module javascript)
- Node.js 14 or newer
- Java8
- mineflayer (via `npm install mineflayer`)
- minecraft 1.12.2 release

## Use
start server with
```
cd Evocraft-py
java -jar spongevanilla-1.12.2-7.3.0.jar
```
then run bot

server.properties onlinemode must be false!

api https://github.com/PrismarineJS/mineflayer/blob/master/docs/api.md#entityattach-entity-vehicle
